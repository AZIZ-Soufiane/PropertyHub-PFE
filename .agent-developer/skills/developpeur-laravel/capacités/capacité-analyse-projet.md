# Capacité: Project Analysis

## Description
Analyze Laravel project state and determine what needs development.

## Process

### 1. Read Specifications
- `1.analyse-besoin/cahier-des-charges.md`
- `2.organisation-contenu/content-strategy.md`

### 2. Check Existing
- Models: `app/Models/*.php`
- Controllers: `app/Http/Controllers/*.php`
- Services: `app/Services/*.php`
- Migrations: `database/migrations/*.php`
- Routes: `routes/web.php`

### 3. Compare
Compare requirements vs existing.

## Output
- Existing features list
- Missing features list
- Development plan
