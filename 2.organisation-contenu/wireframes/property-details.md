# Wireframe: Property Details

## ZONE 1: Header
- **Component**: Navbar (Sticky)
- **Content**: Logo, Main Menu, Back to Search button
- **Action**: Navigation

## ZONE 2: Visual Gallery (Hero)
- **Component**: Image Carousel/Grid
- **Content**: 15+ HD Photos, Fullscreen toggle, Save to Favorites (Heart icon)
- **Action**: Scroll photos, Toggle favorite status

## ZONE 3: Core Info & Action
- **Component**: Flex Container (Two columns)
- **Content**: 
    - Left: H1 [Address], Price badge, Tags (Beds, Baths, Sqft), Description.
    - Right: Floating Booking Widget [Date Picker] [Time Slots] [Schedule Viewing button].
- **Action**: Select slot, trigger booking confirmation.

## ZONE 4: Details & Amenities
- **Component**: Tabbed / Divided sections
- **Content**: H2 "Key Features", Bullet list of amenities, Neighborhood school scores, Map view.
- **Action**: Toggle map, view neighborhood details.

## ZONE 5: Agent Contact (Conversion)
- **Component**: Contact Card
- **Content**: H2 "Meet Your Agent", Michael's photo, Profile summary, Message box [Send Message].
- **Action**: Send in-app message.

## ZONE 6: Footer
- **Component**: standard Footer
- **Content**: PropertyHub navigation links.
