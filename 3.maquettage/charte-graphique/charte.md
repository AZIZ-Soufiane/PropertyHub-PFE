# Style Guide: PropertyHub

## 1. Visual Identity Context
- **Project Name**: PropertyHub
- **Global Tone**: Professional, Premium, Efficient, Modern
- **Core Value**: Real-time reliability and effortless management.

## 2. Color Palette (Tailwind Extensions)

### Primary: Deep Slate Blue (Professional & Trustworthy)
*HSL: 220, 65%, 45%*
- `bg-primary-50`: `#eff3fa`
- `bg-primary-100`: `#dbe4f4`
- `bg-primary-200`: `#bdcfea`
- `bg-primary-300`: `#90addc`
- `bg-primary-400`: `#5d85c8`
- `bg-primary-500`: `#3b65ad` (**Base**)
- `bg-primary-600`: `#2d4f8e`
- `bg-primary-700`: `#264073`
- `bg-primary-800`: `#23385f`
- `bg-primary-900`: `#213151`
- `bg-primary-950`: `#161e33`

### Secondary: Vibrant Cyan (Modern & Tech-Focused)
*HSL: 190, 95%, 45%*
- `bg-secondary-500`: `#029fcaff` (**Accent**)

### Neutrals: Slate (Clean & Premium)
- `bg-slate-50`, `bg-slate-100` ... `bg-slate-950`

### Semantics
- **Success**: Emerald (`bg-emerald-500`)
- **Warning**: Amber (`bg-amber-500`)
- **Error**: Rose (`bg-rose-500`)
- **Info**: Sky (`bg-sky-500`)

## 3. Typography
- **Font-Heading**: `Inter`, sans-serif (Weights: 600, 700)
- **Font-Body**: `Inter`, sans-serif (Weights: 400, 500)
- **Source**: Google Fonts

## 4. UI Components (Preline UI Base)
- **Border Radius**: `rounded-xl` (12px) for cards and modern feel.
- **Shadows**: `shadow-sm` for standard, `shadow-xl` for overlays/modals.
- **Buttons**:
  - `primary`: Rounded-xl, bg-primary-600, text-white, bold.
  - `secondary`: Rounded-xl, bg-white, border-slate-200, text-slate-800.
